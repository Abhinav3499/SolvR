# SolvR Browser Extension

1-click add any LeetCode, Codeforces, GeeksforGeeks, or HackerRank problem directly into your SolvR question tracker!

## How to Install in Chrome / Edge / Brave

1. Open your browser and navigate to:
   - **Chrome**: `chrome://extensions`
   - **Edge**: `edge://extensions`
   - **Brave**: `brave://extensions`
2. Enable **"Developer mode"** (toggle in the top-right corner).
3. Click the **"Load unpacked"** button.
4. Select this directory (`SolvR/extension`).
5. That's it!

## Features

- **Floating "+ Add to SolvR" Button**: Appears in the bottom-right corner when you're viewing any problem on LeetCode or Codeforces. Clicking it sends the problem directly to SolvR with 1 click.
- **Toolbar Extension Popup**: Click the SolvR extension icon in your browser toolbar to preview detected problem details and add it.
- **Configurable SolvR URL**: Works with both your live Vercel deployment (`https://question-tracker-khaki.vercel.app`) and local development server (`http://localhost:5173`).
